# 喵洛阁博客 Wiki

欢迎来到喵洛阁博客的 Wiki 文档中心！这里汇集了博客各个页面的详细介绍和使用指南。

## 博客概览

喵洛阁是一个基于 Astro 构建的极简博客主题，包含丰富的功能页面，记录生活、分享技术、展示作品。

## 技术栈

- **框架**: [Astro](https://astro.build/) - 快速、内容驱动的网站构建器
- **样式**: Tailwind CSS - 实用优先的 CSS 框架
- **组件**: React / Vue / Svelte - 灵活的组件支持
- **部署**: 支持 Vercel、Netlify、Cloudflare Pages 等
